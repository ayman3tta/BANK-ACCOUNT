# 🏠 نظام حساب البيت (Bayt Account)

تطبيق ويب بتصميم **Mobile App** متطور لإدارة المصاريف العائلية وحساب صافي الفلوس وتوقعات الشهر القادم، مع ربط سحابي فوري ومباشر مع **Google Sheets**.

## ✨ المميزات
- 📱 **تصميم موبايل كامل (Mobile App UI/UX)**: شريط تنقل سفلي زجاجي (Bottom Navigation) وشريط علوي مثبت (Sticky App Bar).
- 💰 **حساب فلوسك الصافية بدقة**: بعد خصم إيجار بدر وسيولة البيت وأمانة أختك من حسابك البنكي.
- 🔮 **توقعات الشهر القادم**: قسم مخصص لحساب احتمال فلوسك الشهر القادم (الإيرادات المتوقعة − المصاريف المتوقعة).
- 💸 **إدارة المصاريف**: متابعة مصاريف البيت ومصاريف شقة بدر مع تفاصيل كل بند وتاريخه.
- 🏢 **شقة بدر**: متابعة إيرادات الإيجار ومصاريف التجهيز.
- 🪙 **حاسبة الدهب**: عيار 21 وعيار 24 مع حساب القيمة تلقائياً وتحديث الشيت.
- ☁️ **ربط سحابي مباشر مع Google Sheets**: مزامنة تلقائية وتوثيق كل تعديل في سجل التعديلات مع إمكانية الحذف والتراجع.
